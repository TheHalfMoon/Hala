# H319 — Original dynamic bilingual GUI research (exposed, not blind)

This is a **new, author-original**, local single-file HTML interface named
BeaconBoard with zero external fonts, icons, scripts, images, URLs, packages,
or assets. Every code and station is invented, not a real service, record or
patient. The source and scene definitions are public and therefore **exposed
development research**, not sealed or never-before-seen blind OOD.

It differs mechanically from FieldPort: four visually rearranged station
cards begin as **buttons, not inputs**. The first screenshot-conditioned
native click reveals and focuses a new input; the second independent
screenshot-conditioned prediction may enter a fictional SIM-NN code. Both
English and Arabic RTL, three positions, dark/light themes and four station
targets are preregistered in 12 fixed source cases (6 EN, 6 Arabic).
Scoring independently checks all four source-owned states **after** native
browser dispatch. Wrong button, wrong code, abstention or source mutation
counts as failure or categorical refusal, not success.

The Python policy callback receives **only actual browser PNG bytes and a
bounded user task prompt**. It receives no DOM, reference coordinates, source
code, hidden target, or gold. Source/oracle inspection is in the evaluator;
test callbacks use test-owned DOM geometry solely as fixtures, **not as
neural evidence**. No real model generations are involved in H319 CI.

Run source and invented-fixture tests:

```sh
python -m unittest discover -s tests -p test_h319_original_dynamic_bilingual_browser.py -v
```

To exercise genuine browser dispatch, install the pinned free test
dependencies and use `HALA_H319_BROWSER_QUALIFY=1` and, for Windows Edge,
`HALA_H319_BROWSER_CHANNEL=msedge`. The PR CI runs this on Linux Chromium
and Windows Edge. No GPU, model inference, training, source media export,
private screenshots, release, weights or deployment.
