# H192 — original medium-zoom PRE-action source-native photo close

**Research-exposed original source GUI only. No data admission, no one-shot OOD, no training, no model calls, no screenshots persisted.**

H192 reuses the immutable original public MIT `francoischalifour/medium-zoom` commit `dccda8ab5a1f1677cf1f141d1ead4f14780f0ca4`, its unchanged original `examples/vanilla` demo with the original two photographs, and the H174 pinned source/HTML/license/Vite build and Playwright isolation contract.

The source was **already research-exposed** by H174; the H182 source-role reservation explicitly classifies it `RESEARCH_EXPOSED_UNASSIGNED`. Therefore H192 may demonstrate a new **interaction type** but must never recast it as an unseen held-out OOD, prospective TRAIN, approved DEV, or an independently sealed evaluation source.

Two original native tasks are predeclared, English and Arabic. Each begins with an actual original click on one of the two original photographs; the original medium-zoom code makes an enlarged image and overlay visible. The screenshot is captured **before** the requested source-native **close** action. Only afterward does the browser click the genuinely enlarged original image and require the original zoom overlay to hide, with no JS errors. Both tasks run in **two fresh isolated browser contexts**, with exact PNG and decoded RGBA SHA replay, native zoomed-image target geometry, and distinct screenshot pixels between photographs. Nothing is persisted; screenshot bytes and target coordinates remain in memory and only counts are printed.

Owner-private optional `--historical-root` can reject known prior PNG/RGBA reuse using H185/H186 SHA-only manifests but **cannot establish historical completeness**. It does not read existing H188/H190/H191 private images or source gold, and never opens any consumed H173 benchmark images, old model predictions or labels.

The free GitHub hosted Linux workflow `.github/workflows/h192-mediumzoom-preaction-close-linux.yml` uses the pinned original source and Bun lockfile, first executes the inherited H174 actual browser smoke, and then executes H192 real native open/close replay. A passing synthetic test cannot replace actual hosted/browser evidence.

**Do not publish, train, merge to protected main, or upload original photos/reference data.** Source-only tests and source code may live in this stacked Draft PR. If actual original zoom close behaves differently from assumed click-to-close, correct the app-bound browser action by observing its real source behavior; never fake its success or weaken the source-native outcome gate.
