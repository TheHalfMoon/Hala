# H34 synthetic bilingual visual grounding DEV

H34 adds prospective first-party synthetic GUI images for future neural image inference. It contains 32 fixed cases: four simple application domains, two task languages, and four layouts, with 16 cases per language. Every case has four distinct controls, plausible distractors, and a goal that identifies the intended visible label. Control positions vary across row, column, mirrored RTL row, and scattered layouts. The case oracle (expected label and bounds) remains evaluator-side. The model receives only the rendered image and natural-language goal; target IDs, labels as metadata, and coordinates are never included in its request.

The corpus uses synthetic authored English and Arabic labels. Arabic wording has not received independent human linguistic adjudication, and the generated screens are not real captured UIs. Linux Pillow RAQM is required to shape Arabic. The renderer pins Pillow 12.3.0 and RAQM 0.10.5 and records font revision, exact font bytes, license, image dimensions and PNG SHA-256. The values match a copied CPU-only Kaggle environment probe at [renderer-admission.json](reviews/h34-renderer-admission-20261019.json), SHA-256 `8d9c8b280ccd458dc97c5970a87c259527fa47caa692cc7dfe780b362fe099da`. That CPU observation does not attest the GPU image; the GPU worker independently records and checks its exact package versions before model loading. H34 uses DejaVu Sans `version_2_37`; its upstream archive and exact font member hashes are fixed in `h34/font_pin.json`, and the complete included license is `h34/DEJAVU_LICENSE.txt`. No fallback font is permitted. CPU fake-renderer tests do not qualify typography.

`h34/frozen/cases.json` is the canonical UTF-8 case artifact. Its hash is embedded in the notebook metadata. `tools/build_h34_kaggle.py` requires a clean exact source commit and records a sorted source-content inventory, including the builder itself. It only creates a private Kaggle notebook and metadata; it never submits a kernel. An authorized private research bundle must explicitly be generated with `--research-allowed`; the default bundle denies execution. Its title exactly equals its fixed kernel slug. Linux, retained Kaggle Batch, opt-in, and exclusive new source/output paths are checked before cloning, and resume is refused. The worker independently checks immutable source, renderer, corpus and font-license identity before loading a model. Runtime observations include actual package versions and GPU name, UUID and VRAM and are retained on failure. Telemetry is disabled before library imports, public model loads explicitly use `token=False`, and cache remains at `/tmp/hala-h34-cache` outside output.

The supervisor gives the entire worker, including font fetch, imports, model download/load and generation, a fixed 1,200-second deadline. It owns a new Linux process group, adopts descendants as a subreaper, kills the group and reaps it on exit/deadline. A secondary notebook deadline leaves cleanup time within 1,800 seconds from bootstrap. Each started case writes a pending image-bound record before inference and fsyncs its completed raw row. On timeout the supervisor retains only the actual attempted prefix and any interrupted pending attempt; it never manufactures attempts for the remaining cases. Run metadata explicitly reports incomplete state, observed attempt count and the raw-file hash. Offline Linux CPU tests exercise the actual process deadline and descendant cleanup; they do not establish CUDA cancellation or remote inference behavior. No actual GPU calls were made while implementing H34.

The only evaluated candidate is `Qwen/Qwen3-VL-2B-Instruct` at revision `89644892e4d85e24eaac8bacfd4f463576704203`, loaded with explicit FP16, `trust_remote_code=False`, and `use_safetensors=True`. Inference uses the processor's image path with the actual PNG in the user message and a bounded deterministic generation request. Model output remains untrusted text. Strict parsing rejects duplicate keys, booleans, NaN/Infinity, unsupported fields, malformed points, and values outside normalized `[0,1]`. A valid point is independently mapped to half-open captured-pixel geometry and H29 uniqueness is checked against the complete observed control set.

The auditor recomputes parse validity, gate-valid unique points, semantic target hits, wrong targets, abstentions and errors from raw model output and source-known geometry. It requires exact raw JSON keys, ordered case-prefix IDs, the correct language and error/raw types, the source case hash, and matching case-specific manifest/PNG/raw image hashes. Bounded PNG validation checks dimensions, RGB8 format, chunk ordering/CRCs and decoded compressed scanline size/filters. Image bytes or hashes cannot be swapped while retaining the external raw anchor. The actual bytes hashed before processing are the same in-memory image bytes passed to the processor. Image hashes survive inference failures. Metrics keep all 32 cases in the unconditional denominator and are reported separately for English and Arabic. A unique point on the wrong control is gate-valid but semantically wrong. An externally retained raw-file SHA-256 must be supplied to `python -m h34.audit`; reported summary fields are not trusted. Absent cases count as errors in the final audit. Runtime metadata and this consistency audit are observations, not trusted execution attestations. The model run and audit do not execute actions, invoke application APIs, prove usability, establish quality improvement, or qualify the checkpoint for adoption.

Runtime pins recorded in the generated notebook: torch `2.11.0+cu128`, transformers `5.16.1`, accelerate `1.14.0`, safetensors `0.8.0`, and Pillow `12.3.0`, with RAQM `0.10.5`. The worker requires these versions to be present and does not install them. A mismatched Kaggle image blocks inference while preserving actual observations. Any remote package repair remains a separate authorized bounded operation. The source freeze, independent reviews, supported Graft qualification and exact-head gates remain parent-owned and incomplete until performed.
