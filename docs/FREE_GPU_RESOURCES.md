## Exact provider restrictions and sources

[Kaggle Terms of Use](https://www.kaggle.com/terms), effective June 22, 2025, says: "You will only use the Services for your own internal, personal, non-commercial use, and not on behalf of or for the benefit of any third party". Do not silently treat product R&D as non-commercial. [Notebook documentation](https://www.kaggle.com/docs/notebooks) explicitly calls GPU free and lists specifications, session/storage limits and optional paid Colab promotion. A T4 x2 environment contains two separate devices; do not treat it as one 32 GB GPU. Measure actual device memory and supported precision from the assigned runtime. CUDA/PyTorch image revisions are not guaranteed by the hardware list.

[Colab FAQ](https://research.google.com/colaboratory/faq.html) prioritizes active notebook programming and explicitly prohibits free SSH/remote desktops, primarily interacting through a web UI outside the notebook, and distributed workers. All tiers prohibit unrelated service hosting, remote proxies, crypto mining and account abuse. [Colab Additional Terms](https://research.google.com/colaboratory/tos_v5.html), last modified May 14, 2024, incorporates the FAQ and forbids selling/renting third-party access. [Google Terms](https://policies.google.com/terms) includes "Using Google services on behalf of an organization or business". This supports interactive R&D as a candidate, not a production serving commitment or legal guarantee.

Colab's optional generative AI features collect prompts, code and outputs for product/model improvement and may undergo human review. Avoid these features for Hala work; use normal notebook Python cells and synthetic data. Do not mount unrestricted Drive or access customer files. Fetch only pinned model artifacts to the remote VM after the ordinary notebook runtime and dependencies are qualified.

[Modal pricing](https://modal.com/pricing) includes $30/month compute and states Starter billing begins beyond credits. Shared endpoints are billed from the first token and are not covered by included compute. [Billing](https://modal.com/docs/guide/billing) requires a payment method and describes auto-charges. [Budgets](https://modal.com/docs/guide/budgets) distinguishes pre-credit usage budgets from net-charge spend limits; the documented default is usage limit minus credits (e.g. $100 usage minus $30 credits gives $70 spend). Check the exact account's supported $0 limit before a workload; do not rely on an alert or a Python timer to prevent bills. [Academics](https://modal.com/academics) and pricing offer grant discovery only.

## Official CLI/MCP update

The [Google launch announcement](https://developers.googleblog.com/introducing-the-google-colab-cli/) dated June 5, 2026 explicitly supports developer/AI-agent execution and a fine-tuning workflow. This is evidence of an authorized client: the FAQ's restrictions must not be treated as a blanket ban on all automation. [Official CLI](https://github.com/googlecolab/google-colab-cli) at exact source `d4f855d885cf39f47af5bcae9cd7f7963c18ef09` supports provisioning, `exec`, `run` with automatic teardown, file recovery, logs, and `usage` balance/rate inspection. Its README expressly says **Linux and macOS only; Windows unsupported**. High-memory mode requires Pro/Pro+ entitlement. Neither README nor launch post guarantees free GPU entitlement, grants new credits, or supplies a zero-charge billing commitment. Account eligibility remains a separate check; do not run `colab pay` or silently install an unsupported workaround.

[Official Colab MCP](https://github.com/googlecolab/colab-mcp) bridges a local agent to a Colab session in the browser and requires client tool-list-change notifications. It offers another supported route after legitimate sign-in/session access; no MCP server was installed or configured by this research builder. Evidence is in `research/evidence/colab-cli-official-exa.txt` and the pinned CLI README/source metadata.

[Official ZeroGPU documentation](https://huggingface.co/docs/hub/spaces-zerogpu) currently specifies free personal hosting, Gradio 4+, supported PyTorch 2.8+ versions, default 60-second GPU functions, dynamic allocation and per-tier daily quotas. Larger 96 GB functions consume twice the quota. These conditions supersede older articles saying all personal hosting requires PRO. [Official community-grant guidance](https://github.com/huggingface/skills/blob/HEAD/skills/huggingface-spaces/references/grants.md) targets public research/educational/open-source demos and excludes private/commercial/closed-source projects. A personal free inference demo needs account/deployment qualification; do not claim it provides a commercial always-on service or long training sessions.
