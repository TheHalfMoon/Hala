# Shared Mind/Type pilot operation

Actual update2026-10-16: the fixed116-step pilot completed and original small adapter was retained, with independent integrity and fresh CPU public retrieval checks. Actual pinned-base PEFT attachment and candidate quality remain unqualified. See H21-measured-pilot-20261016.md. The procedure below records the source requirements.

Before training, archive the genuine H21b measured development result and obtain its SHA256 independently. The baseline can use an earlier source commit if the loaded runtime file bytes and frozen H19 implementation/data/settings are identical. The baseline's own immutable source commit is recorded separately from the exact clean training commit. Training requires measured development episode failure or a development Mind semantic deficit; the standalone test Mind diagnostics cannot trigger training.

After the baseline and final training source commit are known, construct the identity dictionary with `base_model`, `base_revision`, `source_commit`, `data_sha256` (H19 dataset file hash), and `evaluation_sha256` (actual baseline file hash). Call `training.adapter_archive.create_bundle` with an empty source directory and `kind='pretraining_roundtrip'`. Commit this harmless manifest to the authorized experimental artifact branch in `TheHalfMoon/Hala`, verify the signed immutable commit, download those exact public bytes into a different directory and externally verify the manifest SHA. Supply that downloaded directory to the trainer. The earlier legacy public probe has a different schema and is insufficient for this interface. A typed commit string alone cannot establish a network roundtrip: the coordinating operator must actually retrieve and independently inspect the pinned commit before invoking training.

On approved free Linux Colab, with exact torch2.11.0 / transformers5.16.1 / peft0.20.0 / Pillow11.3.0 and explicit `HALA_REMOTE_DEVELOPMENT_ALLOWED=1` plus `HALA_REMOTE_TRAINING_ALLOWED=1`:

```text
python -m training.scripts.train_development --bundle H19_DIRECTORY --manifest-sha256 H19_EXTERNAL_SHA --baseline ACTUAL_BASELINE_JSON --baseline-sha256 BASELINE_EXTERNAL_SHA --source-commit CLEAN_TRAINING_COMMIT --probe DOWNLOADED_PROBE_DIRECTORY --probe-sha256 PROBE_EXTERNAL_SHA --probe-commit VERIFIED_ARTIFACT_COMMIT --repository TheHalfMoon/Hala --output NEW_OUTPUT_DIRECTORY
```

No flags vary the schedule. The output directory must be new. The single authored epoch derives 116 steps after excluding 20 Reliance examples from the independently reconstructed 136 rows. Each row's completion prefix is checked on actual expanded processor tokens before model allocation and again during training. Mind receives text only; Type receives the current SHA-verified 800x600 PNG. Raw audit state is removed by projection.

`result.json` is atomically updated with each step's loss, norm, changed tensors, seconds and device memory samples. Memory telemetry is best effort: completed-step evidence is appended before sampling; failures produce null plus a bounded exception class and cannot prevent final persistence or replace the training error. The baseline is hashed and parsed from the same bounded16MiB read; Type PNG reads are bounded2MiB. A final immutable paired checkpoint uses the existing checkpoint publisher and records schedule/data/manifest identities. Its `resume.pt` is local trusted optimizer/RNG state and must never be exported; this pilot has no automatic resume or schedule modification. Failure remains recorded; do not present partial or failed runs as a trained adapter.

`adapter-bundle/` contains only exact original PEFT safetensors/config plus bounded training metadata and the canonical archive manifest. The archive checker requires the full112-tensor inventory. The trainer never edits PEFT config to satisfy archive validation. If official saved bytes are unsupported, retain the failure and fix/review the validator separately. Transfer only this bounded bundle and bounded reports to the authorized signed artifact branch, then independently retrieve and verify the public immutable artifact commit and external SHA before resetting Colab. `trained_pending_durable_archive` explicitly means retention has not yet been established.

For fresh-session evaluation, call `verified_adapter_path(directory, expected_identity, external_manifest_sha256)` before `PeftModel.from_pretrained(base, validated_path, is_trainable=False, ...)`. The helper rejects harmless probes and verifies all archive files before returning a path.
