## Limits

- The only actual GPU evidence supplied is T4 small-tensor FP16 backward work. It does not establish model fit, model output quality, BF16 training, LoRA updates, processor masking, quantization, serving economics, or checkpoint quality.
- The training runner is an unexecuted candidate. The current fixture export is not its SFT image/prompt/completion format; conversion is not implemented. This review does not imply an end-to-end training pipeline exists.
- Baseline smoke uses eight geometric cases and accurately denies complete-task/bilingual release qualification. Baseline evidence labels and aggregate values in preflight remain an input trust boundary requiring reviewed real manifests.
- Cancellation is cooperative: the service signals cancelled contexts and withholds output/capacity release; it cannot forcibly stop arbitrary Python backend work. The mock finishes quickly and the real backend is unavailable.
- Separate security judge is supplied by the parent; this report neither replaces nor independently approves that gate. d1 and typed Jev probabilities are not security/correctness approvals.
