# Implemented architecture and qualification boundary

Hala currently implements one CPU-only contract and control package. `HalaMind.plan`, `HalaType.action` and `HalaReliance.decide` are responsibilities over strict request records and a deterministic fixture backend. They do not represent three trained or resident models. One authenticated loopback service exposes all responsibilities, with bounded ingress/egress, cancellation and deadlines. A real backend deliberately returns `backend_unqualified`.

The independent synthetic executor is confined to Python state dictionaries. The final-state checker reads a detached fixture snapshot and actual executor state. Proposals, postcondition suggestions and `done_proposed` cannot establish completion. The trusted computer authority remains Aladdin, which this project has only read.

The provisional foundation remains Qwen3.5-4B; Qwen3-VL-2B is first in runtime experiment order because its processor path is easier to qualify. All nine candidates are pinned and unqualified. Shared Mind/Type weights with deterministic routing are the simplest initial hypothesis, not a measured winner over architectures A–F. No model is deployed, and no production infrastructure has been authorized.

Data sources are original synthetic fixtures with immutable workflow-family split allocations and record-level source fingerprints. Only train families enter candidate SFT exports. External DragOn asset rights remain unresolved; Hcompany evaluation trajectories remain quarantined. English/Arabic structured fixtures exist, but Arabic screenshot shaping and real visual model performance remain unqualified.

Candidate remote LoRA infrastructure masks prompt/vision tokens, binds all image bytes, freezes base/vision weights, checks finite gradients, and publishes immutable paired checkpoint versions. CPU fault tests qualify artifact handling, not actual model steps or numerical resume equivalence. QLoRA, quantized production inference, live browser/Windows execution and release qualification remain unimplemented or blocked.
