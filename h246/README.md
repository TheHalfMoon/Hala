English) each show a live original calendar after the input is clicked.
A true pointer click selects a distinct visible day (8 through 15) and
a second click on the real original **OK** control commits the date
to the input field. The native selected date string is checked to
match the day the user was asked to choose. Each 960x720 scene captures
one owner-private PNG BEFORE selecting and another AFTER confirming,
plus byte-verified PNG/RGBA SHA256 fingerprints, click pixel
coordinates and source Git/software provenance. All pages are fully
offline using H243 browser context offline mode with all request routes
blocked and service-workers blocked.

A first probe established that clicking a calendar date **without OK**
does not populate the field; H246 therefore requires BOTH UI actions.
No source JS was altered to fake this result.
