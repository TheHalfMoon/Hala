each with a pre-action and post-action private screenshot (16 total).
The H242 capture already checked these frames against 130 known pre-H173
PNG hashes, but had **not** crosschecked them against the other 20

all 16 new H242 raw PNG and decoded RGBA fingerprint values with:
1. H241/H185 pre-H173 SHA-only historical manifest metadata exclusions

2. H198's exact 20 newer quarantined GUI source metadata rows, with
   authenticated per-cohort Git/source pins and no split promotions;
3. the H236 original Dragula research-only JSON receipt (two independent
   EN/AR *contexts*, but only **two distinct before/after visual frames**,
   because H236 kept exactly the same UI fixture in both contexts).

The **H236 duplicate is a real data-quality finding**: context count and
language labels must NEVER be equated with distinct visual inputs. H244
de-duplicates older H236 hashes as exclusions and requires all NEW
H242 frame hashes to be unique among themselves.

The owner Windows H244 verification found zero **known** PNG/RGBA
collisions across these cohorts. It independently **re-opens the 16
new H242 images ONLY**, checks SHA256 PNG and decoded-RGBA SHA against the
