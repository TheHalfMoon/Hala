# Hala

Hala is the independent intelligence system for Aladdin Pro. HalaMind proposes bounded plans, HalaType proposes typed GUI actions, and HalaReliance recommends economical routing. Aladdin retains execution, authorization, and outcome verification.

Status: bootstrap only. No checkpoint has been qualified, trained, quantized, or deployed. Model weights and datasets belong outside Git. Development must remain at $0 out-of-pocket and must not modify Aladdin.

The founder's requirements and evidence-backed implementation will follow on reviewed feature branches.
