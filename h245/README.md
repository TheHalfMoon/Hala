The 16,101-byte public JS file is loaded **unchanged** directly from
the original pinned, clean Git checkout into eight isolated Edge
contexts. All page content, colors, labels, HTML and CSS are authored
for this research by Hala; nothing is fetched from the online demo.

Each case starts with four visible cards. Real HTML5 native dragging
moves the unique numbered first card after the three remaining cards,
and Playwright independently asserts the final original DOM order.
Four contexts have Arabic user instructions and four English.

H243's browser offline switch is required before navigation in every
context, with request routing and service-worker blocking retained.
Each scene saves a private **before** and **after** 960×720 PNG and
their decoded RGBA and PNG SHA256, real screenshot coordinates, the
native DOM oracle and the bounded bilingual task. The output is a new
owner-only create-once directory OUTSIDE Git.
