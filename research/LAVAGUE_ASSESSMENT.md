## Security, privacy and provider defaults

`get_default_context()` in `context.py:34` instantiates `OpenaiContext`, whose defaults are `gpt-4o` and `text-embedding-3-large`; missing `OPENAI_API_KEY` errors. PythonEngine also constructs OpenAI OCR even when some other dependencies are supplied. Do not import these defaults into founder-controlled no-key Hala serving.

Telemetry defaults on when `LAVAGUE_TELEMETRY` is unset. `utilities/telemetry.py:29` sends packed logger records to `https://telemetrylavague.mithrilsecurity.io/telemetry_new`; it removes some screenshot/HTML fields but retains other logs. `agents.py` calls it after runs and QA calls it explicitly. `LAVAGUE_TELEMETRY=NONE` disables this branch. Separately, importing core calls `check_latest_version()` and `utilities/version_checker.py:39` performs a PyPI HTTP request. Disabling telemetry alone does not eliminate outbound traffic. Hala has imported neither module and requires no such telemetry.

Avoid overstating this source version's generated-code execution: the inspected Selenium driver's `exec_code()` at `base.py:311` uses `yaml.safe_load` and dispatches named browser actions. Navigation comments still say "code". Hala should accept schema-validated typed proposals only, with independent target resolution and authorization. Browser control APIs can still execute JavaScript. `DynamicExtractor.extract_as_object()` in `extractors.py:140` directly invokes `eval(self.extract(text))`; copying that parser would cross the untrusted-model boundary and is unacceptable. Use JSON parsing plus strict schemas and bounds.

World-model engine selection, retry counts, membership in a retrieved XPath list and a driver returning without exception are not local authorization and not proof of task completion. `WebAgent`'s model-derived completion flag must never replace a deterministic state transition verifier or trusted Aladdin execution receipt. Page content also enters prompts, so retrieval does not neutralize prompt injection.

## Call reduction and experiment proposal

The concrete reduction opportunities are viewport/interactable filtering and deduplication before model calls; retrieval of a smaller relevant HTML slice; fixed Navigation Controls without an extra navigation LLM; cached provider results for identical immutable input; and stopping bounded retry loops after an executed action. The source does not prove that these reduce total Hala calls: a world-model call plus navigation generation plus embeddings and OCR can increase calls. Measure all calls, tokens, GPU seconds, attempts and independent completion outcomes before adopting an idea.

Compare an owned English/Arabic synthetic browser workflow with (1) full selected DOM plus screenshot and (2) deterministic visible/interactable DOM filtering plus relevant slice. Keep the same checkpoint, image budget, output schema and verifier. Record wrong-target rate, observation truncation misses and total GPU/input work. Evaluate caches only with observation hash, model revision, processor version and prompt hash in the key; cached plans remain proposals and require fresh local authorization.

## Maintenance / license limits

The inspected default branch snapshot's most recent commit predates this assessment by roughly 21 months. Core declares `0.2.35`, Python `^3.10.0`, `llama-index==0.10.56`, `langchain ^0.1.20` and other older ranges; some integrations restrict Python below 3.12. The last commit disables scheduled CI. This is dependency/maintenance review evidence, not a claim that any particular dependency has a known exploit. Do not install this stack without a fresh compatibility/security audit. Upstream Apache-2.0 covers the inspected source; third-party datasets and web content need their own license/provenance checks.
