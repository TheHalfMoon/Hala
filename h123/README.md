## H123 scientific source protocol (source-only until proven)

This is an **English-only targeted complex-UI pilot**. It does not
replace the original Hala bilingual evaluation or claim Arabic progress.
Construct the training pool from the frozen owner-private H71 10,000
original DragOn TRAIN source images and native source-label END boxes.
The H105 approved 512 image IDs and image SHAs are derived again and
compared against `H105_QUALIFIED_PLAN_SHA` before ANY new selection.
**Exclude all previous 512 H113/H122 screenshots** (including all
previous 64 H122 heldout); do not reuse H118/H120 official EVAL scenes.
No hidden TEST, no benchmark response, and no synthetic oracle labels
enter any optimizer input.

From *new*, independent, SHA-bound images select exactly 256 per
complex family: sheet, slide_resize, slider, text_highlight.
Balance real original drag directions, final target 4x4 regions and
distance scales on TRAIN source geometry only, using a fixed seed.
Reserve 32/domain (4 from each of eight original drag directions) as
new never-optimized heldout; keep 224/domain for eventual actual
training. New total: **896 train, 128 heldout**, 1024 unique original
TRAIN images across all four families. Every example has genuine
unaltered image SHA, source intent, original image bounds and START/END
boxes, admitted using the existing H113 geometric normalization and
source round-trip quarantine.

Different H123 END target: a source-defined absolute END point in
normalized 0..1000 plus **two nested spatial grids**, 4x4 quadrant and
10x10 cell. Each cell must contain that same point. No oracle END box or
true point appears in the model prompt; no screenshot is altered.
Invalid JSON, duplicate keys, inconsistent grid or invalid point
must be refused, never silently repaired. Separate H123 trainer and
free GPU run **not yet approved by actual source SHA qualifications**.

## Hard experimental gates

1. Qualify source 10,000 TRAIN labels and original H105 first-512 SHA.
2. Select entirely NEW 1024 original complex UI images; prove new
   train896 vs heldout128 disjointness, direction+region coverage and
   SHA-locked original image/box identity. Keep source details private.
3. Freeze selection and a new heldout scorer **before** candidate GPU
   training; use genuine original TRAIN-only heldout 128.
4. Train a distinct H123 LoRA only on confirmed free noncommercial
   Kaggle T4. Never warm-start from H122 unless a separate qualified
   experiment is explicitly designed. Owner independently reads actual
   optimizer step/gradient and three binary SHA files before evaluation.
5. Require correct END localization in **all 4 complex families**,
   valid point+grid JSON, no modal coordinate collapse, source-sha
   matched response evidence, and meaningful advantage on a new
   original TRAIN-only holdout; no retuning after looking at holdout.
6. Only if source/heldout proof passes use a **new, not previously
   examined official public EVAL** slice. Frozen original H61 strict
   drag scorer and model-produced START/END, never oracle START.
   No external GUI-skill claim until measured.

The previous H122/H120 negative records must remain unchanged.
Never merge/release, deploy, publish images/model weights, use paid
GPU/models, or put original private labels in public GitHub.
