# H187 — genuine original-app PRE-action image readiness

**Research-only native source qualification: NOT a TRAIN/DEV dataset,
model optimization or scored evaluation.**

H180 verified source-native Pickr target interactions but screenshotted
the state *after* the reference action. Those are useful GUI evidence,
but a visual grounding model needs the scene visible *before* acting.
A post-action image must not be quietly relabeled as supervised input.

H187 creates two predeclared bilingual source-native color-selection
scenarios in the same untouched public MIT original Pickr application.
Each uses an earlier **actual original swatch selection** to establish
a different visible starting state, then captures the exact model-visible
**PRE-action** PNG in memory and independently validates the target
swatch changes the original app's displayed color result. Both scenarios
are repeated from scratch in **two fresh Playwright Chromium contexts**
for exact PNG and decoded RGBA digest replay. The gate also requires the
two preaction states themselves to have **different pixels**.

All original sources/builds are verified using the existing H174
immutable original Pickr pin and disposable scratch build contract.
The unmodified Git donor is never edited. No overlays, synthetic
click cues or fake source-native controls are introduced.

The optional owner-only `--historical-root` mode checks both source
preaction PNG/RGBA SHA pairs against the conservative known old-image
metadata exclusions from H185/H186. This catches a *known* reused
old PNG/RGBA, but missing old visual-RGBA data and incomplete source
history still block admitting these examples.

## Free hosted original browser test

`.github/workflows/h187-pickr-preaction-native-linux.yml` separately
retrieves the exact immutable original source and its tracked original
HTML/LICENSE SHA, compiles only the original donor's disposable demo,
uses free Chromium, runs the inherited original H174 smoke and then
the new preaction source-only gate. **Only an actual exact-head hosted
workflow SUCCESS and `H187_REAL_PREACTION_PICKR_SOURCE_REPLAY_ONLY_NOT_TRAIN_DATA`
receipt may qualify this code path.** Synthetic tests alone cannot.

The public CI never receives owner historical data or captures/uploads
images: screenshot bytes, selected colors, and all SHA values remain
inside process memory, and console output contains counts only.

## Why this is not yet model-training data

The two preaction screenshots are never saved to a private dataset,
do not carry verified owner-only supervised action coordinates, and
cannot be included in a training ZIP. No independent complete historical
source/visual-raster exclusion exists, and only one new prospective
TRAIN source is represented. Frappe Gantt, the tentative OOD source,
remains untouched; all consumed H173 v3 OOD is off limits.

Even after a browser proof succeeds, a subsequent **owner-private**
capture and independent original-source replay qualification must
produce many more bilingual/variable-geometry cases across independently
implemented apps, verify known old SHA exclusion, and freeze source
and split manifests before any zero-cost GPU run.

No images/weights/data in public GitHub, no paid GPU, no protected-main
merge, no publication or release. Keep Draft.
