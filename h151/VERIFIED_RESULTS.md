## Failure diagnosis WITHOUT retesting consumed H151

Owner post-hoc case evidence from frozen predictions and gold:

- In the three failed left_up tasks, neural source AND heading points
  were **inside the original visible boxes**. Each intended heading
  model point was about **38 px to the right** of its original visible
  center (vertical error about -12 to +2 px), but H150's screenshot
  difference detector found **no active drop region**.
- A fourth failure in up had an incorrect destination heading point,
  with vertical error about **-61 px**, and also found no active region.
- All 12 cases where H150 detected and retained the visible region
  resulted in actual successful native task persistence.

This narrows the next investigation to **horizontal approach/drop
region robustness near the edge of the destination heading**, alongside
a one-case neural heading grounding error. It is a hypothesis,
not demonstrated causality: no new controller intervention was run
on these consumed cases.
