## Source implementation

Kaggle requires `provider='kaggle'` or `--provider kaggle`; an environment marker alone cannot opt in. `evaluation_guard` admits only Linux, `HALA_REMOTE_DEVELOPMENT_ALLOWED=1`, `KAGGLE_KERNEL_RUN_TYPE` exactly `Interactive` or `Batch`, an existing `/kaggle/working` directory, and no `COLAB_RELEASE_TAG` key. Colab evaluation rejects any Kaggle marker key, including an empty value. The original `remote_guard` remains unchanged for training callers. No cache policy, package pin or inference setting was relaxed.

It does not establish real GPU eligibility, source qualification, model quality or execution authority.
