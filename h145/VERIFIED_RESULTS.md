# H145 — frozen original native drag robustness under imperfect visible points

## Genuine independent owner-Windows result

H144's prior NEW reference-center cohort proved that both direct drag and
three-stage sweep could persist **16/16** actual original React tasks when
given the exact owner-visible card center and heading center. That was
a reference-actuator qualification only, **not** a model score.

H145, with **16 entirely NEW original browser task seeds >=92000** and four
shifted layouts, predeclared a deterministic, bounded perturbation *inside*
the native visible source card and heading rectangles:

- Source: ±20% of card width and height away from its center.
- Visible heading: ±20% of heading width and ±32% of heading height.
- Identical perturbed coordinates to both controllers in isolated original
  browser contexts; neither actuator receives the hidden drop DOM box.
- Each outcome is actual changed application task status **persisting
  after full page reload**, not merely a point-in-bbox classification.
- Four cases each for Arabic/Doing, Arabic/Done, English/Doing and
  English/Done. Four layouts covered; owner source protected.
- The case-level episodes are owner-private in
  `private-h145/noisy-reference-action16-v1.json`.

| Actual one-shot source-only actuator | Genuine persisted success |
| --- | ---: |
| Direct single drag to noisy heading | **0/16** |
| Staged multi-point sweep from the SAME noisy points | **5/16** |
| Both succeeded | **0/16** |
| Only staged succeeded | **5/16** |
| Only direct succeeded | **0/16** |

**Important:** This was *not* 32 neural calls. No H142 model was
evaluated on H145 or improved in this phase; the points were generated
from private owner reference geometry to approximate localization error.
The 5/16 vs 0/16 result is not a Hala model accuracy score, nor a
reliable production controller.

The combined noise makes these cases challenging but does not yet
determine whether start-card mislocalization or destination-heading
mislocalization is the principal cause, or how often noisy clicks start
a genuine HTML5 drag. A fresh H146 factorial study should separately
perturb source, heading, or both, with **no H145 tuning or replay**, and
observe real source drag initiation and persisted target status.
Then a NEW unseen neural cohort should evaluate any preregistered action
controller changes before release.
